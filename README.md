# OLA3 Web Technology - Cash Register System

This project is a web-based cash register assignment.

## Files
- `cash.html` - page structure and UI
- `cash.css` - styling and decoration
- `cash.js` - cash register logic and event handling
- `outline3.txt` - Stage 1 outline + Stage 3 reflection
- `OLA3_Webtechnology_Submission.zip` - submission archive for D2L

## How to Run
1. Open `cash.html` in a browser.
2. Enter the number of items.
3. Click **Scan Items** and enter each item cost.
4. Click **Show Total** to view the result.
5. Click **Reset** to clear the transaction.
